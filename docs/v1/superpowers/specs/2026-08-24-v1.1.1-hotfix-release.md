# BS Coding v1.1.1 Hotfix Release

## Mục tiêu

Phát hành bản vá `v1.1.1` để client nhận hai sửa lỗi sau `v1.1.0`:

- Provider quota cards tự động làm mới phần trăm sử dụng theo chu kỳ và sau khi agent hoàn tất turn.
- Chat không còn giữ quyền auto-scroll khiến người dùng không thể cuộn xuống khi sub-agent đang stream.

## Phạm vi

- Commit regression fix còn chưa commit cho chat scroll.
- Tăng version từ `1.1.0` lên `1.1.1` trong package metadata.
- Thêm changelog tiếng Anh theo `docs/changelog-format.md`.
- Không thêm feature hoặc thay đổi API.

## Quy trình phát hành

1. Xác minh diff chỉ chứa hai bug fix và metadata release.
2. Chạy typecheck, full Vitest suite, production build và chat-scroll Playwright E2E.
3. Commit source fix và release metadata.
4. Push nhánh `master`.
5. Tạo và push tag `v1.1.1`.
6. GitHub Actions build installers Windows/macOS/Linux và job `publish` tạo GitHub Release từ artifacts.
7. Kiểm tra workflow/release đã được kích hoạt.

## Xử lý lỗi

- Không push tag nếu bất kỳ bước kiểm thử hoặc build nào thất bại.
- Nếu push branch thành công nhưng tag chưa push, sửa lỗi rồi tạo tag sau khi xác minh lại.
- Nếu CI release thất bại, giữ nguyên tag và sửa workflow bằng commit riêng; chỉ rerun khi artifacts phản ánh đúng commit tag.

## Tiêu chí hoàn thành

- Version là `1.1.1` trong `package.json` và `package-lock.json`.
- Changelog `v1.0.0 → v1.1.0` không bị sửa; có changelog mới `v1.1.0 → v1.1.1`.
- Typecheck, test, build và chat-scroll E2E pass.
- `master` và tag `v1.1.1` có trên remote.
- GitHub Actions workflow cho tag bắt đầu chạy và release có thể được client updater sử dụng sau khi publish hoàn tất.
