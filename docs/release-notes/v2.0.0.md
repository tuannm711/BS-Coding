# BS Coding 2.0.0

## 🚀 New Features

### Workflow-first V2
- Organize work through Projects and durable Work Sessions instead of terminal-centric panes.
- Plan, execute, review, rework and verify tasks through deterministic persisted lifecycle states.
- Switch provider, account or model without losing canonical Work Session history.

### Providers, usage and settings
- Route across multiple provider accounts with explicit capability, quota and budget policies.
- Track correlated usage and cost confidence through the V2 usage ledger.
- Manage updates and secure Remote Control through typed V2 Settings APIs.

### Safe V1 migration
- Back up V1 sources with SHA-256 manifests before importing projects, agents, sessions and usage.
- Keep the V1 session archive read-only after the one-way V2 writer cutover.

## 📱 Mobile Remote Control — Coming Soon
- The desktop relay supports short-lived pairing, encrypted transport requirements, device revocation and audited V2 commands.
- Stay tuned — the companion mobile client is still in development. 🚧
