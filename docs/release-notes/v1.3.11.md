## What's changed

- **Claude Reasoning Effort Selection**:
  - Added support for selecting reasoning efforts (`low`, `medium`, `high`, `xhigh`, `max`) for Claude models (such as `claude-3-7-sonnet-20250219` and `claude-3-7-sonnet`) in chat via `VariantPicker`.
  - Registered Claude provider models and reasoning options in `models-catalog` and `model-variants`.
  - Safely translated thinking configurations into Anthropic-compatible `budget_tokens` and safeguarded `maxOutputTokens` for reliable streaming.

- **Claude Gateway Quota Tracking & Check Usage Portal**:
  - Implemented automatic quota query via the gateway proxy endpoint (`/api/proxy/check-usage?key=...`), displaying token budget, used tokens, remaining quota percentage, and active session windows.
  - Added direct link/button to the provider's quota check page (`https://agentshop247.com/docs/check-usage?key=...`) on the Quota Account Card.
