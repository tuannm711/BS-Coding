## What's changed

- **Fleet** is a new tab in the right panel: every agent in the project, grouped under the quota pool it actually draws on. Two models that share one pool now sit under one bar, instead of reading as two independent choices when exhausting either exhausts both.
- **Coordination is a grid of live agent chats.** The coordinator sits on the left and every worker it has given work to opens its own full chat beside it, streaming as it runs. It used to be a summary board, which showed nothing between giving a command and getting a result.
- **Sessions moved into the sidebar**, under the open project and split into Coordination and Work, with a dot on whichever session has a turn running. The dropdown in the chat frame is gone.
- **Roles are set in Fleet**, on each agent's row: coordinator, worker, or neither. One coordinator per project — taking the role releases it from whoever held it. An agent with no role is spare quota for fallback.
- **Switching session no longer looks like the agent stopped.** A turn now writes to the session it started in, whatever you select while it runs.
- **Switching session and switching project are fast again.** The session store no longer re-reads and re-parses the whole file on every call.
- A task given to a busy worker now runs as its own turn and is reported when that turn ends, rather than being folded into whatever the worker was already doing.
- A worker that used its tools and wrote no reply is reported as **no reply** with what it ran, instead of being called a failure with no detail.
- A quota refusal now continues on any account in the project, including the coordinator's — it had none before.
- Quota cards are rebuilt for the fixed side panel: shorter labels, badges that fit, and the provider's own long sentence moved to a tooltip.
