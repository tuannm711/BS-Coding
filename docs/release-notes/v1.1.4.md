## What's changed

- Quota windows name the exact reset instant beside the countdown; subscription terms read the same way.
- The chat quota panel shows the request count for the current reset window alongside tokens and estimated cost.
- An account whose Claude or GPT quota is spent no longer reports itself exhausted while its Gemini quota is untouched.
- ChatGPT accounts show their subscription term, read from the sign-in token.
- Windows notification area shows the BS Coding logo instead of the previous branding.
