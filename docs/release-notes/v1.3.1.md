## What's changed

- **Fixed: agents writing out a tool call instead of making one.** In a session with more than one agent, every earlier tool call was being replayed to the model as a line of text rather than as a tool call — so the model produced text in the same shape, and nothing ran. Shared history is now sent as real tool calls, the same way a single agent's own history always was.
- Once one reply had been written out that way, later turns copied it, including across a switch to a different agent. That no longer has anything to copy.
- The warning that appears when a reply looks like a written-out tool call now recognises the form models actually produce, so it still catches the case if it ever recurs.
