## What's changed

- **Google Gemini is now a built-in provider.** Connect with an official Google AI Studio (Gemini) API key and use Gemini models directly in agents and chat, with tool calling supported.
- **ChatGPT and Antigravity sign-in stays inside BS Coding, and keeps BS Coding's own tools.** Signing in runs entirely in the app, and chat still uses BS Coding's agent and tools rather than handing the session to an external runtime. The **Sign in with ChatGPT** option appears only when the Codex CLI is installed, and the Antigravity option only when Antigravity is installed; when a client is installed, BS Coding talks to the backend using that installed client's own version. Multiple accounts per provider keep working, each kept separate.
- **Security: updated dependencies to clear 20 reported vulnerabilities.** Patched transitive packages `@xmldom/xmldom`, `fast-uri`, `hono`, `js-yaml`, `qs`, and `vitest` to their fixed versions.
