## What's changed

- **Updates now install silently and relaunch.** Applying an update no longer opens a separate installer window — it installs in the background and the app reopens on the new version.
- **New providers: DeepSeek and Custom API.** Add DeepSeek with just an API key, or use **Custom API** to connect any OpenAI-compatible endpoint by entering a name, base URL, and key.
- **Antigravity sign-in is detected again.** BS Coding now finds an installed Antigravity app and shows its sign-in method (previously only the API key option appeared).
- **New `/compact` command.** Type `/compact` to compact the current session's context on demand.
- **Simpler Agents settings.** Removed the sub-agent model overrides; a sub-agent now runs on the main agent's model. Roles are decided through coordination, not a settings screen.
- **Removed unfinished placeholders.** The Model Router menu entry and the in-progress Mobile Remote Control have been removed.
