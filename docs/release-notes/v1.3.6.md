## What's changed

- **Edit projects.** Use the project menu to rename a project or change its folder. Agent and session IDs and chat history are retained. The destination must be an existing folder that is not already registered. Folder changes require stopped agents/sessions and closed project terminals; project files are not moved.
- **Workspace colors.** Settings → Appearance lets you choose background, text and primary button colors with a color picker or HEX input. Preview before saving, see text contrast feedback, and restore default colors. Saved colors apply across the app and survive restart.
- **Roomier Settings.** The dialog expands to 1120px when space permits. Narrow windows use horizontal section navigation, while content scrolls separately from the footer. Loading, save feedback and unsaved-change recovery remain visible.
- **Clearer agent chat.** Thinking, Working, Responding and waiting-for-input states follow real events. Progress messages and expandable tool results remain in execution order. Successful final responses show elapsed turn time and a Copy action that preserves Markdown. Failed and stopped turns are not marked as successful results.
- **Streaming stability.** Prose is flushed before tool boundaries, completed responses retain their Copy state, and finishing a turn does not pull a manually scrolled transcript back to the end.
