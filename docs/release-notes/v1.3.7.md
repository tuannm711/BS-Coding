## What's changed

- **Dedicated Quick Messages row.** Saved quick-message buttons now sit below Mode and Agent controls, above the composer, and wrap within narrow panes.
- **GitHub Copilot device sign-in.** Connect with a GitHub verification code. Copy the code, open GitHub, and authorize the account; the app finishes sign-in automatically. Cancel, expiry, rejection and failed reconnect preserve existing accounts. This replaces the authorization-code exchange that required a client secret.
- **Steer running agents.** Send guidance with Enter, the Steer button or a Quick Message while a native agent works. Pending guidance is accepted at the next step within the same session and execution, including when it arrives during a final text response. Edit or remove a pending message before acceptance. Active tools and permission prompts complete in order.
