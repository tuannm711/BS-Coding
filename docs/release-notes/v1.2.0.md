## What's changed

- A turn whose agent runs out of quota now continues on another agent instead of ending. BS Coding picks the closest one — same model on another account first, then the same provider, then another — and says in the transcript what it did and why.
- Quota exhaustion is now recorded against the model family that was refused, so an account with one spent pool and one healthy pool is treated as exactly that. The quota card names which pool is spent.
- New Coordinate mode: an agent can assign work to your other agents and review what comes back, without being able to edit anything itself.
- A coordination view outside the chat, with a row per assignment, links into each worker's own session, and one Stop for the whole fan-out.
- The chat quota card gained a Refresh button, and ChatGPT reset credits are shown and can be spent from it.
