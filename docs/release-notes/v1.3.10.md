## What's changed

- **Claude Provider & Gateway API Integration.** Added official and Gateway API support for Anthropic Claude models.
  - **Connection: Gateway**: Connect to Claude via any compatible API Gateway (default endpoint: `https://api.agentshop247.com/api/claude`) using a static API key and `x-api-key` auth schema.
  - **Connection: Direct API Key**: Connect directly using an official Anthropic API Key.
  - **Models Catalog**: Integrated default support for `claude-3-7-sonnet-20250219`, `claude-3-5-sonnet-20241022`, `claude-3-5-haiku-20241022`, and `claude-3-opus-20240229`, with dynamic `/models` endpoint discovery fallback.
  - **Prompt Caching & Thinking**: Preserved prompt cache breakpoints and extended reasoning support for Anthropic models.
