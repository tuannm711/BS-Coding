## What's changed

- **GitHub Copilot profile fix.** Use a supported GitHub REST API version when fetching account identity, private email and Copilot credentials. This fixes the HTTP 400 failure shown as “Provider profile could not be loaded” after Device Flow authorization.
- **Clearer sign-in errors.** GitHub profile failures now include the HTTP status so authentication and service failures can be diagnosed without exposing tokens.
- **Centered Quick Messages.** The dedicated row below Mode and Agent centers its buttons at wide and narrow pane sizes, including wrapped rows.
- **Provider context and tokens.** Antigravity reads response-level usage, including usage-only final frames and cached/thinking tokens. Compatible providers request streamed usage when supported. The footer separates the latest measured context from cumulative session tokens, retains measured spending after Stop/error and across reload, and identifies configured context budgets when model limits are unavailable. Missing provider measurements remain unknown.
- **Complete long responses.** Native agents honor output limits and finish reasons, continue a final response up to twice when it reaches its output budget, and keep the joined response available to Copy. Repeated characters and Markdown are preserved. Stream disconnects or terminal failures keep partial content and show an error instead of claiming completion; continuations cannot execute tools.
- **Native browser connection.** Chrome now connects through Native Messaging and OS IPC without a network port or expiring pairing code. Install / Repair the helper once, load/reload the updated extension in the chosen profile, then select the profile and assign an existing tab to the current chat. Profile/session bindings reconnect across app restarts. Snapshot references are scoped to a session and invalidated on navigation; queued actions respect cancellation/deadlines and are never replayed. Console/network capture is restricted to owned tabs. The helper ships with the app and uses its bundled runtime.

### Browser setup after updating

1. Open Browser → Install / Repair helper.
2. In your chosen Chrome profile, remove the old unpacked bridge once and Load unpacked from the app’s Extension folder.
3. Open the extension popup → Connect, then select the profile and assign a tab to your chat in BS Coding.

Native runtime verification was performed on Windows with Chromium and the packaged helper. macOS/Linux helper paths and wrappers are tested, but live browser runtimes on those systems remain unverified.
