## What's changed

- **Fleet is organized by agent.** Each agent has a compact card showing its current model, provider account and relevant quota, with Coordinator, Worker and Fast controls.
- **One agent per account quota.** Agents bind to an account and quota pool. Antigravity supports one Gemini agent and one Claude/GPT agent per account. Occupied pools cannot be selected for a second agent.
- **Switch models in chat.** The model selector sits beside the agent picker and offers only models within the agent's quota pool. Models are locked while a session is running or has queued messages.
- **Every agent can be removed.** The initial `bs` profile can be deleted, and an empty agent list remains empty after saving and reopening a project. Existing session history is retained.
- **Quick Messages.** Create, edit and delete named message buttons in Settings → Quick Messages. Buttons appear between Mode and the agent picker and send to the selected agent in the active session. Messages sent while it is working use the existing queue.
- **Lifecycle and queue fixes.** Deleted agents stay deleted when background initialization completes, queued messages are retained across turns, queue badges clear after draining, and quitting during startup no longer crashes the main process.

### Existing configurations

Legacy agents sharing a quota are retained. One keeps the pool; conflicting assignments require review in Settings → Agents. Assign another account/pool or remove a profile before saving. No session history is deleted by quota migration.
