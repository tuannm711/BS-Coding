## Design

Extend ProviderAuthorizationStrategy with a device variant while keeping callback OAuth for other providers. Start produces a verification URL, user code, expiry and a completion function. ProviderManager owns cancellation and uses the existing authorization coordinator and vault persistence. Poll according to GitHub interval, increase on slow_down, and stop on denial, expiry, cancellation or app close. Every await before persistence must respect the session's terminal status. Resolve profile and Copilot entitlement before adding an active account. Runtime credentials continue to refresh as before.

The shared-session coordinator atomically takes unassigned pending messages for the executing session. BsAgentManager supplies that queue to SessionRunner. The loop promotes them to transcript user messages and continues within the same turn, retaining IDs, images, display text and execution identity. Check both before streaming and after stream/tools to cover late text-only messages. Session switching cannot transfer steering to another session.
