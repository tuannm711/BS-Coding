## Contracts

MessageTokens.input represents uncached input when cache breakdown is known; cacheRead/cacheWrite remain separate for costs and context. Current context occupancy is from the latest provider usage, not the cumulative request bill. Missing measurements remain unknown; any configured context budget is labeled as configured. Model output limits are supplied only from exact account capability/catalog metadata. LlmStreamOptions and LoopDeps may expose optional maxOutputTokens.

Long-response continuation is limited to two automatic requests on an explicit output-budget finish; no automatic continuation after user Stop or terminal provider failure. Partial content stays available and a failure/unfinished response cannot claim success. All network/model tests use fixtures.
