# BS Coding v1.3.4 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task (project forbids subagents — execute inline). Steps use checkbox (`- [ ]`) syntax.

**Goal:** Ship v1.3.4: remove Model Router + Mobile Remote and the sub-agent model-override settings, make updates install silently in-app, fix Antigravity detection, add DeepSeek + custom API providers, and add a `/compact` command.

**Architecture:** Seven independent phases sharing only the final version bump. Removals verified by typecheck + green tests; additions/fixes by TDD; the updater and installer by a manual check.

**Tech Stack:** Electron 41 + electron-vite + React 19 + TypeScript strict; Vitest; electron-updater + electron-builder (NSIS); `@ai-sdk/*`.

## Global Constraints
- Product track **V1**; branch `feat/v1-3-4` (off `develop/v1` @ 980fee7). Version bump **1.3.3 → 1.3.4** only at Phase 8.
- Working tree is **CRLF**: use Edit/Write, never `sed -i`.
- `npm run typecheck` + `npm test` green before any task is done.
- Do not merge V2 code. At release, **release/v1's tag-publish `build.yml` must survive the merge from develop/v1** (guard explicitly — it broke in v1.3.3).
- Spec: `docs/superpowers/specs/2026-09-22-v1-3-4-release-design.md`.
