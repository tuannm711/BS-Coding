# BS Coding 1.3.5 verification

Date: 2026-10-01. Workspace: `D:/Projects/BS Coding`. Branch: `develop/v1`.

## Delivered behavior

- Fleet displays one compact card per agent with only relevant quota windows and retained role/speed/refresh/reset controls.
- Native profiles reserve provider/account/quota. Antigravity separates Gemini and Claude/GPT; chat model choices remain within the bound quota. Main-process checks cover Settings, model, account and profile mutations.
- Every profile is removable, including the initial bs profile. Empty settings survive reload. Profile deletion reconciles all saved projects and retains session history. Pending initialization/reload cannot resurrect removed agents.
- Quick Messages support name/content creation, editing and deletion through Settings draft/Save. Toolbar buttons send to the selected project-session agent, queue during execution, and preserve composer drafts. Quick-message-only saves do not restart agents.
- Shared-session queue drains every pending message, publishes updated queue state and retains the remaining queue across turns.
- Quitting before MainApp construction completes no longer dereferences an uninitialized app in before-quit cleanup.
- Settings/profile assignment persistence uses atomic file replacement, writes assignment batches before replacing in-memory state, and restores original config bytes when assignment persistence fails.
