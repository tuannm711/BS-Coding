# v1.3.8 verification — 2026-10-01

## Included scope

The existing Copilot profile hotfix is retained. Quick Messages are centered on each wrapping row below Mode/Agent. Provider context/token accounting and long-response streaming are repaired. Browser connection replacement is a proposal, without product implementation or changes to the user's browser/profile.

## Diagnosed causes

- Antigravity read candidate-level usage only, losing response-level/trailing usage frames. Compatible streaming requested usage only for DeepSeek. Missing SDK counters were converted to zero.
- Input-only responses were not restored, cached input was omitted from fallback context sums, async usage snapshots could cross sessions, and shared-session spending was discarded on Stop/error.
- Antigravity hardcoded an 8,192 output cap. The loop ignored finish reasons and accepted premature EOF. Custom adapters ignored some terminal events; the decoder capped the entire stream at 16 MiB. Content-based overlap deletion removed legitimate repeated letters/Markdown.

## Behavior after the fixes

- Antigravity prompt 100/cache 40/candidates 20/thoughts 5 normalizes to input 60/cacheRead 40/output 25/total 125. Footer context 125 and session Tokens 125 (100 in/25 out) persist through restart. Exact account/catalog limits are used; fallback capacity is marked configured. Unknown usage stays unknown.
- Provider spending is recorded when measured, even on Stop/error. Input-only markers persist without empty model messages or visual bubbles. Newer unmeasured continuation/request cannot reuse earlier measured context; usage received at the Stop boundary is still recorded.
- Explicit output-budget completion permits up to two final-prose continuation requests within the same execution. Tools are disabled and internal continuation prompts are not stored. One joined answer preserves all text for Copy. Failed/disconnected streams keep partial text and cannot claim success. Replays use Responses sequence IDs; repeated prose appends verbatim. Buffer limits apply per frame/JSON document.
