# v1.3.7 verification — 2026-10-01

## Delivered

- Quick Messages have a separate wrapping row below Mode/Agent and above the composer. Narrow-pane selectors also wrap instead of clipping.
- Copilot uses Device Flow with user code, Copy code, browser URL, expiry, Cancel and regeneration. Private device grants remain in main. Cancellation during requests/model loading or app shutdown prevents late persistence; failed reconnect retains original credentials. Closing the modal while obtaining a grant cancels the resulting late session. Provider snapshot updates retain the selected provider/method.
- Human guidance steers the active shared session in the same execution at a provider-step boundary, including after final text streaming. The pending queue supports edit/remove and five messages; overflow rejects the send without failing the active execution. File-reference hints, display text, images and IDs are preserved. Delegated assignments remain separate turns.
- Version metadata and release notes target 1.3.7. Development verification was performed on develop/v1; release promotion follows the repository's develop/v1 → release/v1 → v1.3.7 governance.

## Review and regressions

Independent read-only review identified two P2 issues: late device grants after modal dismissal and missing file-reference preprocessing for shared-session steers. Both were reproduced by tests before their fixes and verified after them. A separate Electron regression proved model/agent selector overflow in narrow panes; scoped wrapping CSS fixed it.

Tests cover cancellation/expiry/denial, polling interval and slow_down, reconnect rollback during model loading, shutdown during grant acquisition, same-turn and late steering, queue limit, pending edit/remove, session switching and preserving parent-directory file references. Electron covers device-code copy, cancellation, denied recovery, snapshot refresh, success, late grant cancellation, quick messages, Enter/Steer and edited guidance.

Preexisting limitations observed by the reviewer: concurrent sessions using the same native agent share an agent-keyed runner, rejected composer drafts are cleared before IPC succeeds, and editing can race consumption. These were not introduced or broadened by this release. Tests verify session switching and independent coordinator queues, not concurrent runs of the same agent.
